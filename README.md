<h2>🧐 Features</h2>

Here're some of the project's best features:

*   Find Available Wifi Networks
*   Find Connected IP Address
*   Find SSID and BSSID of Available Networks
*   Find Signal Streanth of Available Networks

<h2>🛠️ Installation Steps:</h2>

<p>1. Clone this project</p>

```
git clone https://github.com/PavinDas/Wifi-network-Scanner
```

<p>2. Open project folder</p>

```
cd Wifi-network-Scanner
```

<p>3. Run the script</p>

```
python wifi_network_scanner.py
```
